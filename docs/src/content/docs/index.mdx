  <Card title="Rollouts" icon="rocket">

## 60-second start

```sh
brew install dshakes/tap/halo
halo init            # scaffold a policy repo
halo validate        # schema + guardrails
halo rollout plan    # what changes, for whom, ring by ring
```

Then follow the [quickstart](/halos/getting-started/quickstart/). Pre-release (`v1alpha1`), Apache-2.0, self-hosted; anything not yet run against a real third-party system is marked **UNVERIFIED** in the docs.
