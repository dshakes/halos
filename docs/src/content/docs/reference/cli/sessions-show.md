Show one ledger session with its audit chain position (halo-server, audit role)

## Usage

```console
halo sessions show <id|session-id> [flags]
```

## Flags

| Flag | Shorthand | Type | Default | Description |
|---|---|---|---|---|
| `--server` |  | string |  | halo-server base URL (or HALO_SERVER); the session cookie comes from HALO_SESSION (audit role) |

## Global flags

| Flag | Shorthand | Type | Default | Description |
|---|---|---|---|---|
| `--output` |  | string | text | output format: text\|json |
