Enable an MCP server or hook for everyone (profile) or a cohort (toggle)

## Usage

```console
halo enable
```

## Flags

None.

## Global flags

| Flag | Shorthand | Type | Default | Description |
|---|---|---|---|---|
| `--output` |  | string | text | output format: text\|json |

## Commands

| Command | Description |
|---|---|
| [`halo enable hook`](/halos/reference/cli/enable-hook/) | Enable a hook (--event and --command) |
| [`halo enable mcp`](/halos/reference/cli/enable-mcp/) | Enable an MCP server (--url or --command) |
