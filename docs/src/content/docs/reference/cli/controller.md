Automated experiment loop (evaluate, kill on rollback, PRs, notify)

## Usage

```console
halo controller
```

## Flags

None.

## Global flags

| Flag | Shorthand | Type | Default | Description |
|---|---|---|---|---|
| `--output` |  | string | text | output format: text\|json |

## Commands

| Command | Description |
|---|---|
| [`halo controller run`](/halos/reference/cli/controller-run/) | Evaluate running experiments and act on verdicts (never merges) |
