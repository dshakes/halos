Run the supply-chain static scan over a file or directory (exit 2 on findings)

## Usage

```console
halo artifact scan <path>
```

## Flags

None.

## Global flags

| Flag | Shorthand | Type | Default | Description |
|---|---|---|---|---|
| `--output` |  | string | text | output format: text\|json |
