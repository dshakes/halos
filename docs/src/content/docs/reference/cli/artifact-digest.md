Print the artifact digest of a file or directory, to pin it in supplyChain.artifacts[].digest

## Usage

```console
halo artifact digest <path>
```

## Flags

None.

## Global flags

| Flag | Shorthand | Type | Default | Description |
|---|---|---|---|---|
| `--output` |  | string | text | output format: text\|json |
