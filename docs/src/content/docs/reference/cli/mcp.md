Model Context Protocol server for agents

## Usage

```console
halo mcp
```

## Flags

None.

## Global flags

| Flag | Shorthand | Type | Default | Description |
|---|---|---|---|---|
| `--output` |  | string | text | output format: text\|json |

## Commands

| Command | Description |
|---|---|
| [`halo mcp registry`](/halos/reference/cli/mcp-registry/) | The halos.yaml mcp registry of approved MCP servers (ADR-0029) |
| [`halo mcp serve`](/halos/reference/cli/mcp-serve/) | Serve Halos tools, resources and prompts over stdio MCP |
| [`halo mcp token`](/halos/reference/cli/mcp-token/) | Mint a short-lived token for one MCP server whose authorization server is Halos |
